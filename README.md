# DuoLang

6개월 완성 영어회화 학습 웹앱입니다. Duolingo처럼 매일 짧은 레슨을 풀며 XP, 연속 학습, 하트, 보석, 업적을 쌓고, 배운 표현은 간격 반복(SRS)으로 다시 복습합니다.

## 실행

```bash
node server.js
```

브라우저에서 <http://localhost:5173> 을 엽니다. 빌드 과정은 없습니다.

`index.html`을 파일로 직접 열어도 대부분 동작하지만, 자연스러운 온라인 음성과 음성 인식은 로컬 서버(`node server.js`)로 실행할 때 가장 잘 동작합니다.

## 코스 구성

- **초급 A1–A2 · 중급 B1–B2 · 고급 C1** 3개 레벨
- 레벨마다 8개 유닛 × 5개 레슨 = 40레슨, 전체 **120레슨**
- 유닛마다 핵심 표현 12개, 문장 패턴 6개, 대화 2개
- 매일 한 레슨씩 6개월(24주) 완주 설계

## 학습 기능

- **레슨 유형**: 뜻 고르기, 영어 문장 고르기, 듣고 고르기, 단어 조합, 빈칸 채우기, 받아쓰기, 대화 이어 말하기, 따라 말하기
- **말하기 연습**: Web Speech API 음성 인식 + 일치도 점수, 마이크가 없으면 자기 판단으로 진행
- **복습**: 틀린 표현과 학습한 표현을 1·2·4·8·16·32일 간격으로 다시 출제
- **게이미피케이션**: XP, 하트(8분마다 회복), 보석, 연속 학습, 14개 업적, 5주 캘린더
- **온보딩**: 목표 설정, 레벨 선택 또는 9문항 배치고사
- **진행 저장**: 브라우저 `localStorage`에 자동 저장

## 음성 설정

프로필 → 설정에서 목소리와 말하기 속도를 바꿀 수 있습니다.

- **온라인 자연 음성(Google)**: 기기에 영어 음성이 없거나 기본 음성이 기계적으로 들릴 때 사용하는 음성입니다. `node server.js`로 실행하면 로컬 서버가 음성을 대신 받아와 재생합니다.
- **기기 음성**: 브라우저/운영체제에 설치된 영어 음성을 선택합니다. Edge의 `Natural` 음성이나 Google 음성이 있으면 자동 선택에서 우선 사용합니다.
- **자동 선택**: 자연스러운 기기 음성이 있으면 그것을, 없으면 온라인 음성을 사용합니다.
- **말하기 속도**: 느리게(0.8) / 보통(0.95) / 빠르게(1.1)

인터넷이 끊기거나 서버가 없으면 자동으로 기기 음성으로 넘어갑니다.

## 파일 구조

```
index.html              앱 진입점
server.js               정적 파일 서버 + TTS 프록시(/api/tts)
css/style.css           전체 스타일 (라이트/다크, 반응형)
js/app.js               라우터, 전역 이벤트, 온보딩/배치고사
js/lesson.js            레슨·복습·말하기 세션 엔진
js/views.js             홈·복습·프로필·온보딩 화면
js/core/store.js        localStorage 상태, XP/하트/연속/SRS/업적
js/core/speech.js       TTS, 음성 인식, 효과음
js/core/exercises.js    문제 생성기
js/data/course.js       코스 정규화, 레벨, 배치고사
js/data/*.js            레벨별 커리큘럼 데이터
```

## 참고

- 학습 기록은 브라우저별로 저장됩니다. 프로필 하단의 **학습 기록 초기화**로 처음부터 다시 시작할 수 있습니다.
- 온라인 음성은 학습 문장을 로컬 서버를 통해 Google 번역 TTS로 전달합니다. 민감한 문장은 입력하지 마세요.
- 커리큘럼 문장은 앱에 포함되어 있어 오프라인에서도 기기 음성으로 학습할 수 있습니다.
