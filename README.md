# DuoLang

6개월 완성 영어회화 학습 웹앱입니다. Duolingo처럼 매일 짧은 레슨을 풀며 XP, 연속 학습, 하트, 보석, 업적을 쌓고, 배운 표현은 간격 반복(SRS)으로 다시 복습합니다.

## 실행

```bash
node server.js
```

브라우저에서 <http://localhost:5173> 을 엽니다. 빌드 과정은 없습니다.

`index.html`을 파일로 직접 열어도 대부분 동작하지만, 자연스러운 온라인 음성과 음성 인식은 로컬 서버(`node server.js`)로 실행할 때 가장 잘 동작합니다.

## 모바일에서 실행하기

### 1. 같은 Wi-Fi에서 바로 접속

```bash
node server.js
```

실행하면 터미널에 접속 주소가 표시됩니다.

```
DuoLang running
  PC     : http://localhost:5173
  Mobile : http://192.168.0.12:5173   (Wi-Fi)
```

휴대폰을 PC와 **같은 Wi-Fi**에 연결하고, 휴대폰 브라우저에서 `Mobile` 주소를 엽니다.

- 접속이 안 되면 Windows 방화벽에서 **Node.js**의 **사설 네트워크** 접속을 허용하세요.
- 공유기에서 기기 간 통신을 막는 경우(AP isolation) 해당 기능을 꺼야 할 수 있습니다.
- 온라인 음성(TTS)은 PC가 인터넷에 연결되어 있으면 동작합니다.

> 일반 HTTP 주소에서는 모바일 브라우저가 **마이크(음성 인식)**를 막을 수 있습니다. 이때는 말하기 문제가 `직접 판단: 말했어요`로 진행됩니다. 듣기·따라 말하기 음성은 정상 재생됩니다.

### 2. 마이크까지 사용하려면 HTTPS로 접속

음성 인식은 보안 컨텍스트(HTTPS 또는 localhost)에서만 허용되는 경우가 많습니다. 아래 방법 중 하나를 사용하세요.

- **Cloudflare Tunnel**: `cloudflared tunnel --url http://localhost:5173` → 표시되는 `https://...` 주소를 휴대폰에서 엽니다.
- **ngrok**: `ngrok http 5173` → 표시되는 HTTPS 주소로 접속합니다.
- **배포**: Render, Railway, Fly.io 같은 Node 호스팅에 이 프로젝트를 올리면 HTTPS 주소로 어디서든 사용할 수 있습니다.

HTTPS 주소로 열면 마이크 권한을 허용한 뒤 발음 연습까지 사용할 수 있습니다. iOS Safari는 음성 인식 API 지원이 제한적이므로, 마이크 연습은 Android Chrome 또는 데스크톱 Chrome/Edge를 권장합니다.

### 3. 모바일 화면

모바일에서는 하단 내비게이션과 1열 레이아웃으로 자동 전환됩니다. 설정은 `프로필 → 설정 → 목소리`에서 바꿀 수 있습니다.

- 화면 상단·하단의 노치/홈 인디케이터 영역을 피하도록 안전 영역을 자동으로 확보합니다.
- 레슨의 `정답 확인` 버튼은 화면 아래에 고정되어 스크롤해도 항상 보입니다.
- 작은 화면에서는 경로 노드와 여백이 줄어들어 한 화면에 더 많은 내용이 보입니다.
- 목소리 선택, 속도, 하루 목표 같은 설정은 터치하기 편한 크기로 표시됩니다.

### 4. 모바일 웹앱 설치 (PWA) & 전용 아이콘

브라우저의 기본 메뉴를 통해 앱처럼 홈 화면에 설치하여 전체 화면으로 깔끔하게 사용할 수 있습니다.

- **고화질 전용 앱 아이콘 적용**:
  - Android Chrome: `icon-192.png`, `icon-512.png` 및 최신 Android 적응형 규격 `icon-maskable-512.png`
  - iOS Safari: 홈 화면 최적화 규격 `apple-touch-icon.png` (180x180)
- **설치 방법**:
  - **Android**: Chrome 상단 메뉴 `⋮` → `앱 설치` 또는 `홈 화면에 추가`
  - **iOS (iPhone/iPad)**: Safari 하단 공유 버튼 (`⎋` 또는 `↑`) → `홈 화면에 추가 (➕)`
- **장점**: 화면을 가리는 불필요한 설치 배너 없이 브라우저 자체 옵션으로 설치할 수 있으며, 설치 후에는 주소창 없이 네이티브 앱처럼 전체 화면과 오프라인 캐시를 지원합니다.

## 코스 구성

- **초급 A1–A2 · 중급 B1–B2 · 고급 C1** 3개 레벨
- 레벨마다 8개 유닛 × 5개 레슨 = 40레슨, 전체 **120레슨**
- 유닛마다 핵심 표현 12개, 문장 패턴 6개, 대화 2개
- 매일 한 레슨씩 6개월(24주) 완주 설계

## 학습 및 회화 기능

- **레슨 유형**: 뜻 고르기, 영어 문장 고르기, 듣고 고르기, 단어 조합, 빈칸 채우기, 받아쓰기, 대화 이어 말하기, 따라 말하기
- **🤖 Gemini AI 1:1 자유 회화 (프리토킹)**:
  - 사전 대본 없이 자유롭게 영어로 대화하는 실시간 AI 회화 파트너 (일상, 여행, 비즈니스, 면접, 토론 5가지 테마)
  - **다중 API 키 자동 로테이션**: 여러 개의 무료 Gemini API 키를 등록하면, 쿼터 소진(429/403) 시 다음 키로 자동 전환되어 끊김 없는 무제한 대화 지원
  - **대화 맥락 기억**: API 키가 교체되어도 이전 대화 히스토리를 완벽하게 기억하며 4단계(스몰토크 ➔ 핵심 대화 ➔ 돌발 상황 ➔ 피드백) 회화 코칭
  - **실시간 피드백**: 자연스러운 어휘/문법 교정 팁, 한국어 번역 토글, 추천 답변 칩 제공
- **📖 나의 단어장 & 오답 노트**:
  - 실시간 영단어·한국어 검색 및 5대 탭 (전체 / ⭐ 북마크 / ⚠️ 오답·약점 / 🔁 복습 대기 / ✅ 학습 완료)
  - 원클릭 별표 북마크(⭐) 및 현재 목록 N개 맞춤 복습 세션 즉시 시작
- **실전 핑퐁 롤플레잉**: 카페, 공항 입국심사, 호텔, 식당 등 6가지 테마에서 원어민 캐릭터와 음성으로 핑퐁 대화
- **3초 순발력 스피킹 드릴**: 3초 카운트다운 타이머 안에 입으로 영어 패턴을 즉시 튀어나오게 훈련 (+순발력 보너스 XP)
- **단어별 발음 정밀 분석**: 말한 문장을 단어 단위로 분석하여 정확한 단어(초록), 아쉬운 단어(주황), 누락 단어(빨강) 색상 칩 피드백
- **내 목소리 녹음 & 1:1 비교**: 녹음된 내 발음과 원어민 음성을 나란히 비교 청취 (`MediaRecorder` 지원)
- **간격 복습(SRS)**: 틀린 표현과 학습한 표현을 1·2·4·8·16·32일 간격으로 자동 출제
- **게이미피케이션**: XP, 하트(8분마다 회복), 보석, 연속 학습, 16개 업적, 5주 캘린더
- **온보딩**: 목표 설정, 레벨 선택 또는 9문항 배치고사
- **진행 저장**: 브라우저 `localStorage`에 자동 저장, 프로필에서 JSON 백업 내보내기/불러오기 지원

## 음성 설정

프로필 → 설정에서 목소리와 말하기 속도를 바꿀 수 있습니다.

- **온라인 자연 음성(Google)**: 기기에 영어 음성이 없거나 기본 음성이 기계적으로 들릴 때 사용하는 음성입니다. `node server.js`로 실행하면 로컬 서버가 음성을 대신 받아와 재생합니다.
- **기기 음성**: 브라우저/운영체제에 설치된 영어 음성을 선택합니다. Edge의 `Natural` 음성이나 Google 음성이 있으면 자동 선택에서 우선 사용합니다.
- **자동 선택**: 자연스러운 기기 음성이 있으면 그것을, 없으면 온라인 음성을 사용합니다.
- **말하기 속도 미세 조절**: 0.6x ~ 1.4x 정밀 슬라이더, 5대 원클릭 프리셋(0.75x 초보 / 0.9x 편안 / 1.0x 보통 / 1.15x 자연 / 1.3x 원어민), 및 화면 내 번개 배지(`⚡ 1.0x`) 원클릭 순환 지원

인터넷이 끊기거나 서버가 없으면 자동으로 기기 음성으로 넘어갑니다.

## 파일 구조

```
index.html              앱 진입점
server.js               정적 파일 서버 + TTS 프록시(/api/tts)
manifest.webmanifest    PWA 매니페스트 (홈 화면 추가)
sw.js                   서비스 워커 (오프라인 앱 셸 캐시)
icons/                  앱 아이콘 (192/512/maskable/apple)
css/style.css           전체 스타일 (라이트/다크, 반응형)
js/app.js               라우터, 전역 이벤트, 온보딩/배치고사, PWA 설치
js/lesson.js            레슨·복습·말하기 세션 엔진
js/views.js             홈·복습·프로필·온보딩 화면
js/core/store.js        localStorage 상태, XP/하트/연속/SRS/업적
js/core/speech.js       TTS, 음성 인식, 효과음
js/core/exercises.js    문제 생성기
js/data/course.js       코스 정규화, 레벨, 배치고사
js/data/*.js            레벨별 커리큘럼 데이터
```

## 참고

- 학습 기록은 브라우저별로 저장됩니다. 프로필 하단의 **학습 기록 초기화**로 처음부터 다시 시작할 수 있습니다.
- 온라인 음성은 학습 문장을 로컬 서버를 통해 Google 번역 TTS로 전달합니다. 민감한 문장은 입력하지 마세요.
- 커리큘럼 문장은 앱에 포함되어 있어 오프라인에서도 기기 음성으로 학습할 수 있습니다.
